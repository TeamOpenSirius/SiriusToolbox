# Chart validation

Use the Chart window’s conversion and self-test actions. Strict conversion rejects
unsupported or ambiguous SUS input instead of silently dropping notes. ENC operations
require an explicit key and never log it.

# 谱面校验

通过谱面窗口执行转换和自检。严格转换会拒绝不支持或有歧义的 SUS 输入，不会静默
丢弃音符；ENC 操作要求显式密钥且不会记录密钥。
